# 🔒 System Hardening & Cybersecurity Lab

Repositório prático focado nos fundamentos de **Cibersegurança e Prevenção**, abordando técnicas de reforço de sistemas (*hardening*), auditoria de serviços Linux e diretrizes de segurança defensiva.

---

## 📂 Estrutura do Repositório

| Diretório / Ficheiro | Descrição |
| :--- | :--- |
| [`scripts/audit_services.sh`](scripts/audit_services.sh) | Script Bash para auditoria rápida de processos em execução e portas de rede abertas. |
| [`docs/checklist-reforco.md`](docs/checklist-reforco.md) | Diretrizes e listas de verificação para o reforço de servidores Web, BD, FTP e DNS. |
| [`docs/principios-acid-aaa.md`](docs/principios-acid-aaa.md) | Notas teóricas sobre o modelo Triplo A (AAA), Baselines e ferramentas de análise (Wireshark/Nessus). |

---

## ⚙️ Principais Conceitos Aplicados
* **Princípio de Redução de Superfície de Ataque:** Desativação de serviços desnecessários para diminuir a probabilidade de incidentes de segurança[cite: 64].
* **Equilíbrio Segurança vs. Usabilidade:** Implementação de restrições rígidas sem comprometer o funcionamento correto dos sistemas[cite: 64].
* **Gestão de Patches:** Aplicação regular de atualizações de segurança para corrigir pontos fracos descobertos[cite: 70].
